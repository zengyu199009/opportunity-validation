# Opportunity Validation

**Evaluate any product idea by checking competitor density FIRST — before you build.**

Built for solo founders, indie hackers, and anyone evaluating AI/SaaS/micro-SaaS opportunities. Stop wasting months on red oceans.

## What it does

Given a product idea or a list of candidate directions, this skill produces a **decision-ready opportunity list** with 8 fields per direction:

| Field | What it answers |
|---|---|
| Direction | Who, in what situation, why they pay |
| Background | Why NOW (with traceable data) |
| Use cases | 2-3 concrete, day-in-the-life scenarios |
| Payment evidence | Existing products / paying behavior (links) |
| **Competitor analysis** | Density 🔴/🟡/🟢 + head players + pricing + gap + window |
| SaaS path | How to monetize, pricing model |
| Agent feasibility | Can an agent team (OpenClaw/Hermes) build/run it |
| Sources | 📎 traceable links |

## Why it exists

Most failed solo products die from choosing a **red ocean that looked like a blue ocean**. The core rule: **never recommend a direction without checking competitor density first.**

Real example (Sept 2026): AI-visibility/GEO monitoring, local-business AI receptionists, and compliance auditing all LOOKED like blue oceans — each actually had **6-11 mature competitors**. Half of one opportunity list was invalidated by a single competitor check.

AI tool niches turn red in **3-6 months**. "It was a gap last month" is not a reason to build this month.
